# BetterModel USM 3.8.0-nf.1

NightFantasy fork build based on upstream BetterModel 3.8.0.

- Adds ModelEngine-style USM (Use State Machine) animation slot API, lerp-out transitions, and completion callbacks.
- Adds `SkinRig`, `SkinPart`, and `SkinBoneBinding` for modular player skin rigs.
- Adds opt-in pose sampling, atomic player updates, shoulder-pivot arms (`prsa`/`plsa`), and own-hand item hiding.
