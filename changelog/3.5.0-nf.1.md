# BetterModel 3.5.0-nf.1

NightFantasy fork build on BetterModel 3.5.0.

- Upstream 3.5.0: Minecraft 26.3 support, `EntityTracker#spawnCondition`, sealed trackers.
- Keeps the public state animation slot API used by NFMobs USM.
- State animation slots take a completion callback; a replaced slot fades out instead of
  cutting; frame duration is computed from the animators; body yaw interpolates the short way.
